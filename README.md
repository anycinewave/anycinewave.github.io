# CineWave 2.0

Versão estática, sem backend, com:
- visual de streaming responsivo;
- busca;
- filtros por categoria;
- detalhes;
- favoritos via localStorage;
- temporadas/episódios;
- botão de reprodução;
- botão Rave;
- tema claro/escuro.

## Teste local
Abra `index.html`. Para que o carregamento de `data/catalog.json` funcione em todos os navegadores, prefira um servidor local simples.

## Publicação gratuita
O projeto pode ser publicado como site estático em GitHub Pages.

## Catálogo
Edite `data/catalog.json`. Use apenas conteúdo de domínio público, licenciado ou para o qual você tenha autorização. Para cada título, informe a URL oficial/autorizada em `url`.

## Rave
O botão não controla o aplicativo Rave. Ele copia o título e abre o serviço oficial; a compatibilidade depende do que o Rave suporta.
